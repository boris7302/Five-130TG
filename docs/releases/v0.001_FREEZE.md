## Итог линии 0.001

Telegram Mini App «Пятак-130» — рабочий HTML/JS-клиент с портом правил C++ Five-130:

- играбельный стол, ходы одним кликом, модалка итогов партии;
- MatchStore (ключ=значение, IndexedDB);
- cfg `five130tg.cfg`, debug-export, документация модулей;
- обязательный UI по `docs/UI_APPEARANCE.md` (часы, vs, стрелки, якорь, last-move);
- вкладки Профиль / Якорь / Помощь; копирайт в футере;
- мобильный header без наложения часов на rev; desktop shell ~1040px + fullscreen.

**Следующая линия:** `0.002` — только отдельной задачей (см. `docs/plans/roadmap.md`).
