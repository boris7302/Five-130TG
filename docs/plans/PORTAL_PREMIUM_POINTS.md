## 1. Серверная инфраструктура

**Решение:** использовать **сервер** (при необходимости — **несколько** с резервным копированием).

Назначение серверов (ориентир):

| Роль | Примеры |
|------|---------|
| API / бот Telegram | webhook, invoice, auth `initData` |
| Игровой бэкенд | PvP relay, состояние партий, премиум-подсказки |
| Портал | аккаунты, баланс баллов, админ-панель |
| Данные | PostgreSQL / SQLite+Valkey (кэш), бэкапы |
| Резерв | второй инстанс / бэкапы БД и конфигов |

Клиент Mini App (GitHub Pages) остаётся статикой; **истина по премиуму, баллам и PvP — на сервере**.

## 2. Премиум в Five-130TG (игровая аналитика)

Премиум открывает **дополнительную информацию** во время партии (не меняет правила домино сами по себе).

### 2.1. Очки за варианты хода

В списке ходов показывать, **какие ходы дают очки и сколько** (кратные 5 / партия — как в движке).

### 2.2. Остаток костяшек «в колоде+у противника»

Для номиналов **0…6**: сколько камней с этой цифрой ещё «не видно» игроку, то есть то, что он **может посчитать вручную**:

- всего в наборе по правилам;
- минус камни уже на столе;
- минус камни в своей руке;

результат = **рынок + рука противника** (суммарно), с перечислением **какие** кости ещё возможны (где уместно).

### 2.3. Дефицит у игрока

По номиналам **0…6**: какие цифры у игрока **в дефиците** (мало или нет в руке) — подсказка для стратегии.

### 2.4. Угроза «отправить на рынок»

Оценка: может ли **теоретически** противник, имея свои камни **и** рынок, выставить ход, который **отправляет игрока на базар** (нет легального ответа).

### 2.5. Подсказка по наведению на ход

При наведении (desktop) / долгом тапе (mobile) на конкретный вариант хода — подсказка: **как теоретически может ответить противник**, если считать, что у него есть **и рука, и камни рынка** (worst-case / теория множеств, не чит «открытой руки»).

**Реализация:** расчёт на клиенте (движок) и/или на сервере; доступ только если `premium_until` / флаг премиума валиден на сервере.

## 3. Баллы портала (не только Five-130TG)

Покупка **баллов**, которые действуют **во всём портале**, не только в этой игре.

Возможности баллов:

| # | Возможность |
|---|-------------|
| 3.1 | Купить **премиум** за баллы |
| 3.2 | **Подарить** баллы другому игроку |
| 3.3 | Тратить баллы в **других играх** портала |
| 3.4 | При большом балансе — **приоритетное общение** с разработчиками |

---

## 4. Два вида баллов

| Вид | Цвет (UI) | Как появляются | Котировка / права |
|-----|-----------|----------------|-------------------|
| **Покупные** | **красные** | Покупка (Stars / ЮKassa / др.) | Базовая валюта портала |
| **Наградные** | **синие** | Выдача создателями портала; за пожертвования; за раскрутку (пример: привели **10** новых пользователей по коротким ссылкам/промокодам → **100** синих) | **Выше** красных: больше прав, большие скидки на премиум; разработчики могут **подарить премиум на год**, списав фиксированное число синих за выдающиеся результаты на сервере |

Правила обмена/приоритета списания (красные vs синие при покупке премиума) — зафиксировать в отдельной таблице тарифов при реализации.

**Вывод синих в деньги (предварительно, 2026-07-21):** режим **A** — без публичного вывода; **задел под B** (ручные заявки админу). Автовывод не делаем. Подробности: [`VALKEY_DATA_MODEL.md`](VALKEY_DATA_MODEL.md) §3.3.

## 5. Панели управления

Обязательны UI/админка:

| Панель | Кто | Функции (минимум) |
|--------|-----|-------------------|
| **Владелец / админ портала** | создатели | выдача/списание синих и красных; промокоды и реферальные ссылки; выдача премиума; просмотр балансов и аудит; модерация |
| **Игрок** | пользователь TG / портала | баланс красных/синих; история; покупка баллов; покупка премиума; подарок баллов; статус премиума; реферальные ссылки/промокоды |

Авторизация: Telegram `user.id` (+ позже аккаунт портала).

## 6. Зависимости и очерёдность (черновик)

```
Сервер (API + БД + бэкапы)
    ├── Аккаунт / баллы (красные, синие) + админ/игрок панели
    ├── Платежи → зачисление красных баллов
    ├── Рефералы / промо → синие баллы
    ├── Премиум-флаг → подсказки §2 в Five-130TG
    └── PvP relay (отдельный трек, см. v0.002_pvp_telegram.md)
```

Рекомендуемый порядок внедрения:

1. Сервер + модель пользователя + красные/синие баллы + админ-панель (минимум).  
   Реализация v0.003: [`ADMIN_PANEL.md`](ADMIN_PANEL.md) (владелец `@bk1804`, назначение админов, регистрация через `user.touch`).
2. Покупка красных (Stars / ЮKassa) + покупка премиума за баллы.  
3. Премиум-подсказки §2.1–2.5 в Mini App.  
4. Рефералы → синие; подарки баллов; приоритет поддержки.  
5. Использование баллов в других играх портала (по мере появления игр).
