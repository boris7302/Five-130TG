### PvP — ожидаемый результат 0.002

**Цель пользователя:** два человека на **двух устройствах**, каждый со **своего
Telegram-аккаунта** — без этого PvP не считается выполненным.

- **Этап 2 (приоритет):** relay-сервер + `initData` на аккаунт + invite (`startapp=match_id`).
- **Этап 3:** синхронизация ходов (polling / WebSocket), «не ваш ход» на клиенте и сервере.
- **Этап 4:** уведомления бота (по возможности в той же линии).
- **Этап 1 (опционально / dev):** hot-seat на одном устройстве; в движке частично есть,
  в UI не подключено — **не заменяет** кросс-девайс PvP.

## Не в scope 0.002 (→ 0.003+)

- Полный offline resume PvP без сервера
- CloudStorage как замена relay
- Flutter Web parity
- Массовый рефакторинг tg.html / engine.js
