Замечания и требования (хронологически):

1. UI appearance (обязательный документ для всех GUI): спиннер/первый ординар
   как Linux §7; часы YY/MM/DD HH:MM:SS, день недели; vs жёлтым; цветные жирные
   стрелки ↑↓←→.
2. Подсветка последнего хода противника — обязательна для всех GUI.
3. Баг ветки Up: дубль 6|6 / вертикаль «боком» при малом maxVert — отложенный
   загиб §5.7 (как в Linux).
4. Четыре пресета якоря rust/amber/slate/ink (default amber); last-move без neon,
   цветные точки по профилю.
5. 0|0 и 6|6 нельзя ПЕРВЫМ камнем любой игры (§2.2b) — в движке и RULES_125.
6. «Победа!» в модалке итога — крупнее, ярко-красным.
7. Вкладка «Помощь»: правила игры + правила пользования; без путей docs/... в UI;
   постраничная прокрутка; FAB между Якорь/Профиль; нижняя кнопка для mobile.
8. Mobile cache: на телефоне оставалась старая Help — ?appver= + unregister SW.
9. Футер: (C) Boris Bulatov (Boris Games), 2026. Five-130 for Telegram, v.xxx Rev. xxx.
10. Mobile header: дата/часы не должны перекрывать Rev и другие надписи.
11. Desktop header: очки и камни крупнее, больше расстояние; «очки»/«камни» мелким
    шрифтом над значениями; очки жёлтым.
12. Desktop: окно узкое при открытии — ~2× шире (shell 1040px, fullscreen на desktop).
13. «очки»/«камни» строго по центру над цифрами.
14. «Вы» и «ПК» — под цифрами камней, чтобы «камни» визуально по центру.
15. Freeze 0.001 — после проверки UI и оформления docs/chats/archive.

Статус обработки: выполнено (rev.#027–#043). Линия 0.001 закрыта 2026-07-16.
