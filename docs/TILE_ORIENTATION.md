# ОБЯЗАТЕЛЬНАЯ ориентация камней на столе (Five-130TG)

**Статус:** жёсткое правило. Нарушение = баг UI.  
**Версия:** 0.001 (2026-07-16).  
**Код:** `web/js/engine.js` → `boardSnapshot()` (`orientMain`, `orientVertAxis`, `tileIsDouble`).  
**Эталон Linux:** `Five-130/docs/graphics_rules.txt` §2.1–§2.2.

Любая правка раскладки **обязана** сохранять таблицу ниже.  
Регрессия «дубль вертикальный на ветке up/down» **запрещена**.

---

## 1. Определение дубля

Дубль = `lo === hi` (0|0 … 6|6).

В коде ориентации **запрещено** полагаться только на флаг `tile.isDouble`
(он может пропасть при клоне/сериализации). Использовать:

- `tileIsDouble(t)` → `t.lo === t.hi`
- `ensureTile(t)` → восстанавливает `isDouble` / `pipSum` / `label`

---

## 2. Таблица ориентации (закон)

`horiz = true` означает камень **плашмя** (ширина > высоты): половинки слева/справа.  
`horiz = false` — камень **стоймя** (высота > ширины): половинки сверху/снизу.

| Ось / участок | Ординар (`lo ≠ hi`) | Дубль (`lo === hi`) |
|---------------|---------------------|--------------------|
| **Главная линия** (влево / вправо) | горизонтально (`horiz=true`) | **вертикально** (`horiz=false`) |
| **Ветка вверх** (вертикальный участок) | вертикально (`horiz=false`) | **горизонтально** (`horiz=true`) |
| **Ветка вниз** (вертикальный участок) | вертикально (`horiz=false`) | **горизонтально** (`horiz=true`) |
| **Хвост загиба** ветки (горизонтальный участок после ↺) | горизонтально | **вертикально** |

### Запрещено

1. Рисовать дубль **вертикально** на вертикальном участке ветки **up** или **down**.
2. Разную логику для up и down: оба направления — **одна** функция `layoutBranch` / `orientVertAxis`.
3. «Угадывать» ориентацию по флагу `isDouble` без проверки `lo === hi`.
4. Начинать загиб **на дубле** вертикальной оси (уводит дубль в хвост с
   `horiz=false`). Загиб — на следующем ординаре (`graphics_rules` §5.7;
   `BEND_REQUIREMENTS.md` §4.3).

### Смысл правила

Дубль всегда **поперёк** направления цепочки (как в классическом домино и в Linux §2.1–§2.2).

```
Главная (→):   [3|5]═[5|5]═[5|2]     дубль 5|5 стоймя
                    ║

Ветка вниз (↓):     ║
                  [1|5]               ординар стоймя
                    ║
                 [6|6]                дубль 6|6 ПЛАШМЯ (не стоймя!)
```

## 3. Реализация (обязательный контракт)

```text
orientMain(tile)     = !tileIsDouble(tile)   // главная + гориз. хвост
orientVertAxis(tile) =  tileIsDouble(tile)   // ветки up и down, вертикальный участок
```

`layoutBranch(tiles, goingUp, …)` вызывается **дважды**:

- `layoutBranch(branchUp, true, …)`
- `layoutBranch(branchDown, false, …)`

на вертикальном участке **оба** ставят дубль через `pushTile(..., horiz=true, ...)`.

---

## 4. Регрессионный тест (обязателен перед выкладкой)

Файл: `tools/test_tile_orientation.js`

Проверяет как минимум:

1. На `branchDown` дубль (напр. 6|6) → `horiz === true` (вертикальный участок).
2. На `branchUp` дубль (напр. 3|3) → `horiz === true`.
3. На главной линии дубль (напр. 2|2) → `horiz === false`.
4. Те же проверки для «голых» камней `{lo,hi}` **без** флага `isDouble`.
5. **Хвост загиба up→влево:** камни с `bent` — ординар `horiz === true`, дубль `horiz === false`; `x` левее спиннера.
6. **Хвост загиба down→вправо:** то же по ориентации; `x` правее спиннера.

Запуск:

```bash
node tools/test_tile_orientation.js
```

Ожидание: `TILE_ORIENTATION OK`.
