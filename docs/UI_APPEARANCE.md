# ОБЯЗАТЕЛЬНЫЙ внешний вид графического клиента (Five-130 / Five-130TG)

**Статус: ОБЯЗАТЕЛЬНО к исполнению.**  
**Версия документа:** 0.001 (2026-07-16).  
**Область:** Telegram Mini App (`web/tg.html`, `cfg/five130tg.cfg`) **и** любые  
будущие **графические** клиенты Five-130 / Пятак-130, в том числе:

- standalone **Windows**;
- standalone **Linux**;
- standalone **macOS** (Mac);
- другие графические ОС и оболочки (например BSD с GUI, мобильные оболочки вне Telegram, WebView-обёртки, Electron / Tauri / Qt / Flutter Desktop и т.п.).

Текстовый TUI (FTXUI) **не** входит в область этого файла.

Связанные: [TILE_HIGHLIGHT.md](TILE_HIGHLIGHT.md), [TILE_ORIENTATION.md](TILE_ORIENTATION.md),  
[BEND_REQUIREMENTS.md](BEND_REQUIREMENTS.md), `graphics_rules.txt` §7 (Linux TUI — отдельно).

## 1. Верхняя полоса (header)

Слева направо (обязательная компоновка):

| Зона | Содержание |
|------|------------|
| Слева | Название **Пятак-130** + версия `v0.001 (rev.#NNN)` |
| Между названием и часами | **Игрок1 vs Игрок2** жёлтым шрифтом (`color.matchup` / `player.name.0` / `player.name.1`) |
| Центр | **Дата и время** крупными цифрами, формат **`YY/MM/DD HH:MM:SS`** |
| Справа от часов | **День недели:** `пн` \| `вт` \| `ср` \| `чт` \| `пт` \| `сб` \| `вс` |
| Край справа | Счёт / камни в руке (как принято в клиенте) |

### Настройки (cfg) — обязательные ключи

```
ui.clock.enabled=1
ui.clock.format=YY/MM/DD HH:MM:SS
ui.clock.font_size=1.35rem
ui.weekday.enabled=1
ui.matchup.enabled=1
player.name.0=Вы
player.name.1=Компьютер
color.matchup=#ffd24a
```

Часы обновляются не реже 1 раза в секунду.

## 2. Подсветка якорей на столе

1. **Закрытый центральный дубль (спиннер)** — стиль из `ui.spinner.style`
   (`rust` \| `amber` \| `slate` \| `ink`, **по умолчанию `amber`**): рамка + фон + точки.
   Выбор в UI: кнопка «Якорь». Без неоново-красного ореола.  
2. **Первый ординар** — `color.opening.border` (см. TILE_HIGHLIGHT.md).  
3. **Последний ход** — в том же профиле якоря: спокойная рамка + **цветные точки**
   (не neon-cyan). Настройки: `spinner.style.<id>.last.border|face|pip`.  
   На ходе текущего игрока это **ход противника**. Дубли последнего хода этой
   подсветкой не отмечаются (спиннер / обычная рамка).

Прочие дубли «якорной» рамкой спиннера не подсвечиваются.

Приоритет рамок: спиннер → первый ординар → последний ход → центр → обычная.

| Стиль | Якорь (рамка / фон / точки) | Последний ход (рамка / точки) |
|-------|-----------------------------|-------------------------------|
| `rust` | `#6b3f1e` / `#efe4d4` / `#5c3317` | `#8b4513` / **бордовые** `#b71c1c` |
| `amber` (default) | `#b8860b` / `#fff3d6` / `#6b4a12` | `#a67c00` / **красные** `#c62828` |
| `slate` | `#4a5d73` / `#e2e8f0` / `#2f3e4f` | `#546e7a` / **синие** `#1565c0` |
| `ink` | `#3d2914` / `#f0ebe3` / `#3d2914` | `#5d4037` / **пурпурные** `#6a1b9a` |

## 3. Стрелки направлений хода

Стрелки в панели ходов (и в аналогичном UI standalone) **обязаны** быть:

- чуть **жирнее** обычного текста UI;
- раскрашены по сторонам света:

| Направление | Стрелка | Цвет (cfg) | По умолчанию |
|-------------|---------|------------|--------------|
| Север (вверх / BranchUp) | ↑ | `color.arrow.up` | `#3b82f6` синий |
| Юг (вниз / BranchDown) | ↓ | `color.arrow.down` | `#ff3b5c` красный |
| Запад (влево / MainLeft) | ← | `color.arrow.left` | `#a855f7` фиолетовый |
| Восток (вправо / MainRight) | → | `color.arrow.right` | `#eab308` жёлтый |

Ключ `color.arrow` (устаревший общий) не отменяет цветные направления.

## 4. Портируемость

Те же правила §1–§3 действуют для:

- Telegram Mini App (текущая реализация);
- графических standalone **Windows / Linux / macOS (Mac)**;
- любых других графических ОС и оболочек (desktop WebView, Electron, Tauri, Qt, Flutter Desktop, мобильные клиенты вне Telegram и т.д.).

**Не** относятся к текстовому TUI (FTXUI): там — `graphics_rules.txt` и cfg `setup_five125.cfg`  
(включая `frame_last` для последнего хода).
