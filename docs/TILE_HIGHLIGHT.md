# Подсветка якорей на столе (Five-130TG)

**Статус:** обязательное правило отображения.  
**Версия:** 0.001 (2026-07-16).  
**Эталон Linux:** `Five-130/docs/graphics_rules.txt` §7; `cfg/setup_five125.cfg`.

## Приоритет рамок

1. **Закрытый спиннер** (`isSpinner`) — `color.spinner.border` (по умолчанию `#ff1744`, яркий красный; толстая рамка + свечение). Как Linux `frame_spinner_closed`, но в TG визуально **ярче**.
2. **Первый ординар** (`isOpeningOrdinary`) — `color.opening.border` (по умолчанию `#ffd24a`, как Linux `frame_opening=yellow`). Постоянно, пока центр — ординар.
3. **Последний ход** (`isLastMove`) — `color.last.border` (по умолчанию `#00e5ff`, как Linux `frame_last=cyan`). Только **ординары** из последнего хода; на вашем ходе это ход противника. Сбрасывается при следующем ходе.
4. **Центр-дубль до спиннера** (`isCenter`) — `color.center.border` (`#d4a017`).
5. Обычные камни — рамка игрока.

## Правило

- Если игра открыта **ординаром** → этот камень (центр) всегда с `frame_opening`.
- Если игра открыта **дублем**, после закрытия с двух сторон → `frame_spinner_closed` на спиннере (в центре или на плече).
- Прочие дубли не подсвечиваются рамкой спиннера.
- Ординары последнего хода — яркий cyan (`frame_last` / `color.last.border`), пока не сделан следующий ход.

См. также обязательный [UI_APPEARANCE.md](UI_APPEARANCE.md) (шапка, часы, стрелки, vs, последний ход) —
для TG и всех будущих графических клиентов (Windows, Linux, macOS и др. оболочки).
